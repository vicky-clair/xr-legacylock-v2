# LegacyLock V2 接口与配置索引

适用版本：0.2.0；与[开发维护指南](开发维护指南.md)配套。这里记录当前实现，不定义尚未实现的 API。

## 1. 调用约定

组件通过 `vaultClient.call<T>(method, ...args)` 调用业务。`desktopBridge.commandSpecs` 将方法映射为 Rust 命令和具名 DTO；JavaScript 使用 camelCase 参数，Rust 命令接收对应 snake_case 参数。允许空值的参数按命令定义处理，其余类型错误由 Tauri/服务拒绝。

宿主检查发送窗口为 `main`。耗时命令通过 `backend::run` 执行；繁忙返回 `TRY_LATER`。只有 `status/getItem/searchItems` 在桥接层按 50ms 间隔最多重试 20 次，写命令不自动重试。

原生文件对话框由 Rust 打开。取消返回 `{ canceled: true }`；正常动作可能返回直接 View 或包含 `view` 的对象。导出返回路径，不能据此推导拥有任意路径读写权限。所有权、格式、容量和 epoch 均在服务端检查，隐藏按钮不是权限控制。

## 2. 业务命令

下表参数为前端调用顺序，不包含桥接自动创建的 progress Channel。公开状态命令不表示可以读取资产。所有者操作也可能受到本机身份、版本、双凭据、演示只读或挑战令牌等附加规则约束。

| 前端方法 → Rust 命令 | 参数 | 主要结果/约束 |
|---|---|---|
| `status → status` | 无 | 公开存在性、版本或损坏状态；不返回资产 |
| `newSecret → new_secret` | 无 | 新 LL3 随机安全密钥 |
| `initialize → initialize` | password, secret | 本机无库时创建所有者 View；继承会话不能初始化 |
| `unlock → unlock` | password, secret | 所有者 View；继承接管仍需本机身份及版本检查 |
| `lock → lock` | 无 | 立即撤权并广播事件，不等待工作槽 |
| `localUnlockStatus → local_unlock_status` | 无 | available、remembered 状态 |
| `unlockLocal → unlock_local` | password | DPAPI 取回安全密钥后解锁，仅锁定状态可用 |
| `setRememberedSecret → set_remembered_secret` | enabled, password, secret | 所有者设置；启用必须重新验证双凭据 |
| `getItem → get_item` | id | 当前会话单条完整资产；所有者/继承人可读 |
| `searchItems → search_items` | query | 命中 ID 数组；搜索词最多 4096 UTF-8 字节 |
| `saveItem → save_item` | item | 所有者提交资产，返回新 View |
| `deleteItem → delete_item` | id | 所有者删除资产，返回新 View |
| `settings → settings` | settings | 所有者更新密库内加密设置 |
| `preferences → preferences` | 无 | 公开本机显示偏好 |
| `setPreferences → set_preferences` | preferences | 所有者持久化显示偏好 |
| `scan → scan` | 无 | USB 列表及新 token 集合 |
| `provision → provision` | primary, secondary, password, secret | 所有者双盘重配，返回 view 和路径 |
| `sync → sync` | primary | 所有者主盘同步，返回版本和路径 |
| `recover → recover` | primary, secondary | 原生选择备份后建立只读 View |
| `importOwner → import_owner` | password, secret | 选择完整备份并导入，拒绝不安全覆盖 |
| `importData → import_data` | password, secret | 所有者合并来源资产，返回 view、imported |
| `export → export` | password, secret | 所有者重新认证后选择加密导出位置 |
| `credentials → credentials` | password, secret, newPassword, newSecret | 验证旧凭据并重包装 owner 槽 |
| `health → health` | 无 | 当前会话源一致性、签名和认证状态；异常撤权 |
| `prepareDestroy → prepare_destroy` | password, secret | 所有者获取两分钟一次性 token |
| `destroy → destroy` | token, confirmation | token 与版本/epoch 匹配且输入 DELETE 后删除本机文件 |
| `importAttachments → import_attachments` | 无 | 所有者原生多选，返回附件草稿；尚未写入资产 |
| `exportAttachment → export_attachment` | itemId, attachmentId | 当前会话原生选择明文输出位置；拒绝覆盖 |
| `copy → copy` | text | 当前会话复制文本，约 30 秒后条件清理 |
| `viewLanguage → view_language` | language | 临时同步 zh/en/ja 原生菜单显示，不持久化 |
| `windowControl → window_control` | action | minimize/maximize/close/quit/tray 枚举 |

另外 `desktopBridge.activity()` 直接调用 `activity`，刷新自动锁定计时；它不在业务 `Method` 映射中，也不授予会话。

## 3. DTO 与事件

| DTO | 字段和语义 |
|---|---|
| View | role、id、revision、recovery、items、settings；items 实际为摘要，尽管当前 TS 使用 VaultItem[] 类型 |
| 摘要 | id、title、category、createdAt、updatedAt，以及原数据有定义时的 revision；不将缺失 revision 补成 null |
| Settings | autoLockMinutes：1/5/15/30/60；heirName 最多 200 UTF-16 码元；heirNotes 最多 10000 |
| Preferences | theme、zoom、subscriptionDemo、language、closeToTray 五个固定字段 |
| Drive | token、root、label、size；root 用于显示，后续 USB 操作必须使用 token |
| 本机记忆状态 | available 表示平台适配器能力，remembered 表示记录存在，不承诺记录可解密 |
| Progress | `{ stage: 'choosing' \| 'scanning' \| 'processing' }`，没有伪造百分比，也不携带秘密 |

九个耗时入口使用 Channel：附件导入/导出、扫描、双盘配置、同步、恢复、所有者导入、数据合并、加密导出。每次调用使用独立 Channel，完成或锁定后忽略迟到进度。

`secure:locked` 是宿主广播的无秘密事件。前端收到后递增本地 epoch，清空视图、编辑器和凭据，并刷新公开状态。宿主的 Rust epoch 与前端 epoch 是各层独立计数，不通过 IPC 强行同步数值。

## 4. 配置说明

| 文件 | 关键字段/维护点 |
|---|---|
| `package.json` | 版本、精确前端依赖、dev/build/tauri/测试/两种打包脚本；保持 package-lock 同步 |
| `Cargo.toml` | 四个 workspace 成员；默认成员仅 core 和 reader；release 为 opt-level 3、thin LTO、单 codegen unit、保留 unwind |
| `rust-toolchain.toml` | 固定 Rust 及 rustfmt/Clippy，避免本机默认版本导致构建漂移 |
| 各 crate `Cargo.toml` | 核心协议、服务、阅读器和宿主依赖边界；平台 API 放在适用 target 依赖中 |
| `tsconfig.json` | ES2022、bundler 解析、严格检查、noEmit、React JSX；`src` 为检查范围 |
| `tsconfig.node.json` | Vite 配置的 TypeScript 项目设置 |
| `vite.config.ts` | 127.0.0.1:1420、相对资源地址、dist 输出、禁 source map、阻断参考/旧 Electron/模拟模块 |
| `index.html` | 本地页面容器与前端入口，实际运行语言由 i18n 更新 |
| `src-tauri/tauri.conf.json` | productName、version、identifier、开发/构建命令、主窗口和 CSP；默认不生成安装包 |
| `src-tauri/tauri.preview.conf.json` | 启用 NSIS、当前用户安装、中英日语言、图标和说明/许可证资源；缺 WebView2 时联网引导安装 |
| `src-tauri/tauri.offline.conf.json` | 覆盖 webviewInstallMode 为 offlineInstaller；配合 preview 配置使用 |
| `src-tauri/capabilities/main.json` | 只授权 main 窗口及明确命令、事件监听；不授予通用文件、shell、HTTP 权限 |
| `src-tauri/build.rs` | 生成命令权限定义的唯一手写清单 |
| `src-tauri/permissions/autogenerated/`、`src-tauri/gen/` | 构建生成权限与 schema，不手工修补 |
| `src/services/ui-messages.json` | 以原提示文本为键的翻译数据；严格 JSON，不插入代码注释 |
| `.github/workflows/verify.yml` | Windows 自动检查、未签名测试打包、reader 构建及证据上传 |
| `reference/manifest.json` | 冻结源码版本与逐文件 SHA-256；不是新版代码清单 |
| `docs/dependencies/` | 锁定依赖清单和原始许可证文本，使用生成脚本更新 |

窗口默认 1180×800、最小 800×500，`create:false` 表示由 Rust 建立窗口并安装导航策略。禁用前端拖放默认能力。运行时 CSP 默认拒绝外部资源，允许本地脚本、样式和 IPC；开发 CSP 另外允许固定本机 Vite HTTP/WebSocket。

主题白名单为 royal_violet、cyber_cyan、obsidian_gold、electric_magenta、abyssal_navy；缩放为 0.85/1/1.15/1.25。显示语言为 zh/en/ja；演示订阅状态为 trial/expired/monthly/quarterly/yearly。切勿把演示枚举作为实际付费授权依据。

## 5. 常见错误处理

| 错误码 | 处理原则 |
|---|---|
| `LOCKED`、`OWNER_REQUIRED` | 清理过期展示或要求合法所有者凭据，不能改前端 role 绕过 |
| `TRY_LATER` | 等待当前操作结束；只读可按桥接策略重试，写入需明确重新发起 |
| `COMMIT_UNCERTAIN` | 撤权并保全文件，重新读取确认磁盘版本，禁止声称已回滚 |
| `LOCAL_VAULT_CHANGED` | 磁盘不再是预期版本，锁定后重新打开，不能覆盖外部修改 |
| `OLDER_BACKUP`、`DIFFERENT_LOCAL_VAULT`、`LOCAL_VAULT_DAMAGED` | 保留本机与来源；不要删除本机文件来绕过导入保护 |
| `AUTHENTICATION_FAILED`、`INVALID_SIGNATURE` | 检查凭据和备份完整性，不降低校验强度 |
| `LOCAL_KEY_UNAVAILABLE` | 改用手动双凭据，合法所有者可取消或重新启用记忆 |
| `USB_NOT_PRESENT`、`USB_SCAN_FAILED`、`USB_SCAN_TIMEOUT` | 重新连接并扫描；继承会话检测失败按撤权处理 |
| `TWO_PHYSICAL_DRIVES_REQUIRED` | 选择两块实际物理 USB，不是同盘不同分区 |
| `OUTPUT_EXISTS_OR_UNAVAILABLE` | 使用新输出文件名，或排查权限；导出不覆盖已有文件 |
| `CONFIRMATION_REQUIRED` | 重新验证并申请新挑战；旧 token 不可重用 |
| `INVALID_SIZE`、`INVALID_ITEMS` | 按协议限制调整数据；不要仅放宽 UI 限制 |
| `TRAY_UNAVAILABLE` | 保持窗口可见，避免隐藏后无法恢复 |

错误对外只传稳定代码。不要在错误、日志、进度或遥测中插入密码、LL3 密钥、VMK、签名私钥、附件内容和资产秘密。诊断时使用合成样本，并将代码缺陷与实机未验收状态分别记录。
