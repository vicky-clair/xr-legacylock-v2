# LegacyLock Tauri 2 + Rust 分阶段验收清单

日期：2026-09-24。所有复选框均为待执行，不代表已完成；设计依据见 [开发设计与迁移规范](开发设计与迁移规范.md)。

## P0：冻结与建项

- [ ] 新建独立项目、应用 ID 与用户数据目录，保留旧项目。
- [ ] 冻结源码、依赖锁文件、文件哈希、黄金样本及 UI 截图。
- [ ] 核对 24 分类、三栏布局、全部功能矩阵和最新本机记住密钥行为。
- [ ] 测量同一参考机上 Electron 安装版、便携版启动/内存/交互基线。
- [ ] 固定 Rust stable、Tauri 2、CLI/API/插件兼容版本。

## P1：协议与阅读器

- [ ] canonical_js 覆盖 UTF-16 排序、字符串转义、整数与缺失值。
- [ ] AES-GCM、scrypt、Ed25519 DER、HKDF 与旧实现互通。
- [ ] Node→Rust、Rust→Node、交叉修改后读取全部通过。
- [ ] Unicode、附件原始字节、可选字段、修订号及时间无损。
- [ ] 旧副盘在主盘单独更新后哈希不变且可恢复。
- [ ] 错误凭据、错误身份、错误代次、单盘、篡改及超限输入拒绝。
- [ ] 独立 reader 无 WebView/Node/联网依赖，明文输出有明确提示且不默认覆盖。

## P2：UI 与权限

- [ ] 原 React 组件、三栏、五背景、三语言、缩放及订阅测试保留。
- [ ] 添加资产常用类型优先，完整分类可搜索，附件只保留“添加更多”入口。
- [ ] 查看与编辑分离；空字段隐藏，秘密切换后重遮盖。
- [ ] 命令有固定 DTO/错误码/取消语义与统一 bridge。
- [ ] AppManifest 应用命令 ACL 已显式定义，capability 仅给 main 必要能力。
- [ ] 远程来源、任意路径、shell 和不必要网络能力均关闭。
- [ ] Windows/macOS/Linux 焦点、dialog、滚动、字体及小窗口实测。

## P3：所有者与数据

- [ ] 原双凭据创建/解锁及凭据更换有效。
- [ ] 记住密钥默认关闭，启用重新验证，系统存储无明文降级。
- [ ] 不自动搬运 Electron safeStorage 文件，旧用户手动验证后重新启用。
- [ ] 密钥库不可用/密文损坏时可手动解锁、取消记忆。
- [ ] 所有写操作串行，锁定 epoch 使在途授权失效。
- [ ] 文件替换各阶段故障注入通过，失败不清空、不假成功。
- [ ] owner 导入保留原身份/设置/双盘，冲突生成副本。
- [ ] 导出/改凭据/双盘配置/删除仍要求手动双凭据。
- [ ] 删除令牌单次且有时效，移除限定本机文件及记住密钥，不删外部备份。

## P4：继承、USB 与桌面

- [ ] 只读导入不覆盖本机，可查看合法旧备份及另一身份备份。
- [ ] 继承人直接调用写 API 均拒绝，不能用本机记住密钥接管。
- [ ] 同物理 USB 两分区拒绝；扫描 token 在写入前复验。
- [ ] 副盘只存份额，日常更新只需主盘。
- [ ] 真实拔插、盘符变化、写保护、满盘、断电及跨平台文件系统测试。
- [ ] 托盘资源真实解码/创建通过，失败时窗口不隐藏。
- [ ] 关闭三选项、系统锁屏、睡眠、剪贴板故障、单实例及文件锁通过。
- [ ] 退出与强制结束后的恢复状态明确，启动不恢复已解锁会话。

## P5：性能与体积

- [ ] 参考机信息、WebView版本、冷热启动定义及 p50/p95 原始记录完整。
- [ ] 100/1,000/10,000 项及附件场景均有测量。
- [ ] 虚拟列表与按需详情不破坏键盘操作、秘密隐藏或只读权限。
- [ ] 比较 opt-level=3/s、LTO 与依赖裁剪后的速度/体积。
- [ ] 完整进程树内存统计，不能只统计 Rust 主进程。
- [ ] 精简包、运行库、完整离线包、安装后占用分别报告。
- [ ] 无 Node sidecar、CDN、参考源码、测试资源、真实密钥或无用插件进入发布包。

## P6：交付

- [ ] 平台构建、应用签名/公证、包内资源及 SHA-256 检查通过。
- [ ] 安装、升级、卸载和新旧应用并存不会误删/并发覆盖密库。
- [ ] 断网创建、解锁、导出、两种导入、双盘及阅读器通过。
- [ ] Windows 运行库缺失路径可理解且有完整离线安装方案。
- [ ] macOS 用相应平台集成/人工测试补齐 WebDriver 空缺。
- [ ] 性能未达或平台未测项目明确标记，不当作完成项。
- [ ] 用户手册、迁移指南、恢复说明、已知限制和版本记录交付。

验收记录格式：`条目 / 平台与版本 / 输入样本哈希 / 执行命令或步骤 / 期望 / 实际 / 日志路径 / 结论 / 日期`。禁止在日志、截图和缺陷报告里放真实密码、安全密钥或用户资产。
