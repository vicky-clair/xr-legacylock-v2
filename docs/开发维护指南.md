## 4. 关键业务数据流

### 4.1 创建、解锁与角色

初始化由 Rust 生成密库 ID、VMK 和 Ed25519 签名密钥。密码和 LL3 安全密钥共同派生 owner 槽的包装密钥。所有者会话含签名私钥，继承会话仅有 VMK；是否能写入由这个能力差异决定，不能通过传入 `role: OWNER` 改变。

普通启动始终锁定。打开服务只读取偏好和取得进程文件锁。解锁验证外部签名、双凭据、私钥对应公钥及解密后数据结构，最后才安装活动会话。

### 4.2 保存与失败边界

1. `backend::run` 获取工作槽并记录 epoch，耗时工作在阻塞线程执行。
2. 服务取得操作互斥锁，核对 epoch、所有者能力和适用的业务限制。
3. 复制候选会话，变更数据，服务端生成时间和版本，验证后重新加密签名。
4. 写入同目录随机临时文件，`sync_all`，读回并验证完整内容。
5. 核对磁盘仍是 `expected` 版本，保存上一完整版本到 `.previous`。
6. 再次核对 epoch，执行平台替换，并读回验证目标文件。
7. 提交成功后安装候选会话；失败不把未确认的候选当作已保存状态。

替换开始后的错误统一按 `COMMIT_UNCERTAIN` 处理：磁盘可能已有新版，不能简单认定旧版仍在，更不能自动重试写入。应锁定、保全文件并重新读取。故障注入和子进程退出验证不等价于真实断电验证。

### 4.3 锁定与异步竞态

锁定首先递增 Rust epoch，旧任务随即失去授权。会话互斥锁暂时被快照持有时，延后清理只清除旧代次会话，不能误删之后新建立的合法会话。

宿主在返回结果前再次检查 epoch。前端桥接和 App 也各自丢弃锁定前开始的回复，并清除详情、编辑器、凭据输入与进度。前端处理是显示保护，不能替代服务端检查。Rust 的可清零缓冲区和 JSON 字符串清理不代表能保证清除 JavaScript 历史字符串、系统交换文件或所有内存副本。

### 4.4 导入、合并与凭据变更

- 所有者导入使用完整 LVCF 3 备份：保留密库身份、资产、附件、设置和恢复配置。已有本机文件时拒绝不同身份、较旧版本或损坏文件覆盖。
- “导入数据”要求已有所有者会话：相同记录跳过；同 ID 不同内容生成新 ID 副本；保留本机设置和恢复配置。
- 更换密码/安全密钥只重包装 owner 槽，保留 VMK 与已有双份额恢复能力。
- 显式重配双 USB 会重新验证凭据、轮换 VMK 并生成新恢复代次。旧份额不能解密新封套；已存在的旧备份仍应按其原代次管理。
- 旧 Electron 本机记忆文件不自动迁移，首次仍需原密码和 LL3 安全密钥。

### 4.5 USB 和本机记忆

Windows 扫描器使用固定系统 PowerShell 路径和固定编码脚本，仅枚举 USB，排除启动/系统盘；有 15 秒超时及 2 MiB 输出限制。扫描生成五分钟有效 token，重新扫描会替换 token 集合。使用时核对盘符和物理身份，拒绝同一物理盘的两个分区。

主盘保存 `LegacyLock/<id>/<generation>/primary.llkey` 和 `vault.llvault`，副盘仅保存 `secondary.llkey`。重配先完成两盘写入和恢复验证，再提交本机；崩溃遗留目录保留，重试寻找未占用代次。日常同步只访问主盘。继承会话每约五秒检查设备；由于枚举耗时，这不是严格五秒的撤权上限，也未实现即时设备事件撤权。

本机记忆使用当前 Windows 用户 DPAPI 封装安全密钥，记录绑定密库 ID、公钥及 owner 槽摘要。显式启用需要重新验证双凭据。失配或解密失败时使用手动解锁；凭据/恢复配置变化使旧记忆失效。DPAPI 不是跨机器、跨系统账户的备份方式。

### 4.6 大列表与附件

列表接口只返回 ID、标题、分类、时间和可选资产版本；详情经 `getItem` 按需获取。搜索在 Rust 内匹配标题、用户名和备注，前端以 120ms 去抖提交。超过 200 项启用固定 76px 行高的窗口化渲染；改行高必须同步计算及键盘焦点逻辑。

附件保留旧格式 data URL。单个附件最多 2 MiB，单资产最多 100 个附件，完整资产数组的规范化 JSON 最多 20 MiB，外层文件最多 32 MiB。Base64 会增加体积，所以总容量不是原文件大小的简单相加。附件导入先进入草稿，保存资产后才能按 ID 导出；附件导出是明文。

## 5. 数据位置与兼容规则

应用 ID 为 `com.legacylock.tauri.preview`。实际路径取自 Tauri `app_data_dir`，Windows 通常为 `%APPDATA%\com.legacylock.tauri.preview`。安装版和便携版共用此用户目录，便携并不表示数据写在 EXE 旁。

| 文件 | 用途 |
|---|---|
| `vault-v3.llvault` | 当前加密密库 |
| `vault-v3.llvault.previous` | 上一完整版本，不等于独立长期备份 |
| `vault-v3.lock` | 进程排他文件锁载体 |
| `appearance-v1.json` | 本机非秘密显示偏好 |
| `local-key-tauri-v1.json` | DPAPI 封装安全密钥及绑定信息 |
| `*.tmp-<48 位十六进制>` | 当前文件所属临时记录，正常路径退出清理；崩溃时可能遗留 |

不能直接接管原项目 `C:\XMWJJ\xr-LegacyLock` 的数据库目录。迁移使用原版导出的 LVCF 3 `.llvault`。`vault.locked` 和任意历史导出格式不在通用兼容承诺中。

协议固定 AES-256-GCM、scrypt `32768/8/1`、Ed25519 DER、HKDF-SHA256 和 JavaScript 兼容规范化。对象键按 UTF-16 排序、数字按 ryu-js 表示，serde_json 开启 `float_roundtrip`。不能为“简化代码”改成普通 JSON 序列化或 Rust 字符数。孤立 UTF-16 surrogate 被拒绝，不做有损替换后继续验签。

## 6. 修改代码时的同步要求

新增命令需同时修改 `commands.rs` 或 `main.rs` 的实现、`generate_handler!` 注册、`build.rs` 清单、`capabilities/main.json` 和 `desktopBridge.ts` 的 DTO 映射，并更新桥接测试。不要给 WebView 添加通用 fs、shell 或 HTTP 权限来绕开原生命令。

新增资产字段要同步前端类型/表单、Rust 白名单/长度限制和互操作样本。未知字段当前会被拒绝，不能只修改界面。分类、主题和语言同样需要同步客户端定义与服务白名单。

修改磁盘事务必须保留读回校验、expected 检查、previous、撤权检查和不确定结果处理。修改 USB 流程必须验证失败重试保全旧代次、同物理盘拒绝和主盘单独同步。

中文注释说明模块职责、业务约束和失败原因，不逐行复述语法。自有源文件、测试与脚本均有中文入口说明；协议、服务和宿主关键方法另有流程注释。严格 JSON 配置的字段说明放在[接口与配置索引](接口与配置索引.md)，不加入会导致解析失败的注释。第三方依赖、生成文件、锁文件、构建产物和冻结参考快照不手工批量注释。

## 8. 打包、收集与体积说明

必须串行执行；精简和离线打包共用 NSIS 目标文件名，后一次会覆盖前一次的构建输出，所以每次成功后立即按对应类型收集。

```powershell
cargo build -p vault-reader --release --locked
npm run package:preview
./scripts/collect-release.ps1
npm run package:offline
./scripts/collect-release.ps1 -Offline
```

产物收集到 `releases/0.2.0-test-win-x64/`。`collect-preview.ps1` 只是兼容旧入口。只有在程序、前端和嵌入资源均未变化且已有成功构建时，才可使用 `tauri bundle` 单独重新封装；不要以它替代源代码变更后的完整构建。构建器会临时修补 EXE 的安装类型标记，哈希校验应在打包完全结束后执行。

2026-09-27 已生成产物的实测大小如下；MiB 按 1,048,576 字节计算，后续运行库版本变化会影响大小。

| 文件/组成 | 字节 | 约 MiB |
|---|---:|---:|
| 应用 EXE | 11,968,512 | 11.41 |
| 精简 NSIS 安装包 | 2,949,770 | 2.81 |
| 便携 ZIP（含阅读器、说明和许可证） | 4,676,326 | 4.46 |
| 微软 WebView2 离线运行库安装器（构建缓存） | 212,213,456 | 202.38 |
| 完整离线 NSIS 安装包 | 217,925,700 | 207.83 |
| 独立阅读器 | 581,120 | 0.55 |

离线包的绝大部分体积来自 WebView2 运行库。Tauri 的界面使用这个运行库；精简包在缺少它时联网获取，离线包则预先携带 x64 安装器，供无运行库、无网络的电脑安装。应用本体没有因此变成约 208 MiB。外层安装器压缩后的大小不能用各原文件大小精确相加，已压缩的运行库也不能期待再缩小到几 MiB。

已有 WebView2 的测试机器可用精简包；需要给断网且缺运行库的机器安装时使用离线包。便携 ZIP 也依赖系统 WebView2，独立 Rust 阅读器则不需要。移除运行库可以减小离线包，但会失去在缺运行库电脑上完全离线安装 UI 的能力。本次未更改这两种打包策略。

## 9. 发布交接

依赖变更后运行 `node scripts/dependency-notices.cjs` 更新依赖清单与许可证原文。该清单不是法律审查结论。版本号需要同步 npm、Rust workspace、Tauri 配置及用户说明；更换应用 ID 会改变数据目录，需要另做迁移设计，不能为了去掉 Preview 字样随意更改。

发布前核对包内文件、版本、SHA-256、签名状态、说明和许可证，并在独立环境测试安装升级卸载及断网运行。当前应用和安装包均为 `NotSigned`；内置微软运行库的有效微软签名不能替代本应用签名。旧应用及真实用户数据保持独立，任何测试通过都不能代替真实用户备份。

本次文档与注释维护不修改业务逻辑，也不重新发布已有安装包。开发文档以本仓库 `docs/` 为准，已有测试包里的说明是其构建时快照。
