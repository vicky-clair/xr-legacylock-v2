## 实机验收仍需执行

- 两块实际 USB：同物理盘双分区拒绝、换盘符、拔插、重插、主盘单独更新、副盘 SHA-256 不变。
- NTFS/exFAT/FAT32 适用介质：写保护、无空间、文件占用、配置/同步中拔盘及断电，保全旧代次。
- 原生窗口：1180×800 / 800×500，高 DPI、五主题、三语言、缩放、长备注、秘密重遮盖、虚拟列表键盘和附件对话框。
- 托盘存在/不存在，关闭三分支、第二实例、睡眠/锁屏、剪贴板被其他程序替换。
- 精简/离线安装、升级、卸载与旧应用共存、断网创建/导入/导出/恢复；核验安装器不删除用户数据。
- 代码签名、发布资产签名及来源、依赖许可证清单。没有签名证书，不伪造已签名状态。

当前只有一块系统识别的 USB，未执行双物理 USB 写入。未对密码管理器进行桌面 UI 自动化，因此这些项目明确保留为未验收。测试包只面向 Windows，不宣称三平台完成或可直接商用。
