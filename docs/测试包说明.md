# LegacyLock V2 使用与迁移说明

版本：0.2.0 Windows 测试版；日期：2026-09-27。

## 安装与数据位置

优先使用 x64 安装包。精简包依赖系统 WebView2，缺少时会联网获取；带 offline 后缀的包包含离线运行库安装器。便携 ZIP 同样依赖系统 WebView2，不会把保险库保存在 EXE 旁。

独立应用标识为 `com.legacylock.tauri.preview`，Windows 用户数据通常位于 `%APPDATA%\com.legacylock.tauri.preview`，以 Tauri app_data_dir 为准。主文件为 `vault-v3.llvault`，上一完整版本为 `vault-v3.llvault.previous`。测试版安装与便携程序共用此目录；不能同时编辑。旧 Electron 数据目录保持独立。

## 旧版数据完整迁移

1. 在原应用中解锁，导出加密的 `.llvault` 信息备份。保留旧应用、旧数据和独立备份。
2. 启动 V2，选择所有者导入，选择该文件并手动输入原密码和 LL3 安全密钥。
3. 首次导入保留原密库身份、资产、附件、设置和恢复配置。核对资产数量、字段及附件后再开始新增修改。
4. 已有所有者会话使用“导入数据”合并：相同记录跳过，同 ID 的不同内容生成副本；本机身份、设置和双盘配置保留。
5. 原本记住密钥的用户仍需首次手动输入两项凭据，然后在新版主动重新启用本机记忆。

支持冻结旧实现的 LVCF 3 格式，不代表任意历史版本或 `vault.locked` 均可直接读取。不能把 `.llkey` 当信息备份。孤立 UTF-16 surrogate 等解析限制见协议兼容策略；不支持时拒绝导入并保留原件。

锁定状态下导入同一密库的旧版本会被阻止，以免回滚；不同密库也不会覆盖本机。可以在另一个 Windows 用户账户测试独立导入。

## 日常使用

创建时设置至少 12 位密码，并把生成的 LL3 安全密钥保存到独立安全位置。启动始终锁定；默认需要密码和安全密钥。

查看、编辑分开，切换资产重新隐藏秘密。附件单个最多 2 MiB，总数据仍受原协议容量约束。在“添加更多”选择文件，保存资产后才能导出该附件。附件导出是明文，使用原生保存对话框且拒绝覆盖已有文件。

本机记住密钥使用 Windows 当前用户 DPAPI 加密；它不会进入普通备份。损坏或不可用时改用手动双凭据；所有者可取消记忆。凭据更换及显式重配双盘会取消记忆，普通资产保存保留。

订阅界面仍是明确标注的本地演示，没有真实付款、许可服务器或扣费。

## 主副 USB 与继承恢复

首次配置需要两块不同的物理 USB，不能选同盘的两个分区。主盘保存 `LegacyLock/<id>/<generation>/primary.llkey` 和 `vault.llvault`，副盘只保存 `secondary.llkey`。

日常更新只接主盘并执行同步。副盘不读写；换密码后仍可使用原份额恢复。只有显式重配才轮换 VMK、恢复代次和份额。部分写入失败保留旧代次，新一次配置使用未占用代次；不要混用不同代次份额。

继承恢复：连接两盘，扫描并选择主副盘，再选择加密信息备份。只能读取，不能修改本机。允许读取合法旧备份或另一密库；接管必须手动提供该备份的双凭据，并通过本机身份及版本检查。设备消失或扫描失败会撤销继承会话；当前还需真实 USB 拔插验收。

USB 文件可以复制，设备身份检测不是硬件防克隆保证。继承姓名和说明是备忘，不执行身份认证、通知或自动授权。

## 写入失败与恢复

不要删除原文件。正常保存先写同目录临时文件、同步、读回验签、保留 previous，再替换并验证。结果不确定时强制锁定，重新打开检查版本，不继续沿用旧会话编辑。

若主文件损坏，先退出程序，复制保全整个独立数据目录；使用离线阅读器检查备份和 previous，确认可读后再由人工进行恢复。程序不会把损坏文件自动重置为空库。故障注入和进程退出测试不等于真实断电验证。

关闭可选择锁定并隐藏、退出、取消；托盘不可用时保留窗口。正常退出等待已接受的写入结束。系统锁屏、睡眠、超时和托盘隐藏撤销会话。剪贴板约 30 秒后清除，只有内容仍等于本应用复制值才清除。

删除需要双凭据验证和两分钟内输入 `DELETE`；令牌一次性且绑定当前版本。只移除本机密库、previous、专属临时记录及本机记忆，不删除外部备份。普通删除不是介质安全擦除。

## 独立恢复阅读器

```powershell
.\vault-reader.exe owner backup.llvault recovered.json
.\vault-reader.exe recovery backup.llvault primary.llkey secondary.llkey recovered.json
```

所有者模式交互隐藏输入凭据，不把密码放命令行。输出是包含秘密和附件的明文 JSON；拒绝覆盖已有输出。输出失败可能留下部分明文，请自行妥善保管或清理。
