# 继承人使用手册 · LVCF 3

## 原电脑或其他电脑只读访问

1. 启动应用，插入配置成功的主、副两块物理 USB。
2. 在锁定页或「加密导入导出」的「导入信息数据」选择「双 U 盘 · 只读」，扫描并选择两盘。
3. 点击「选择信息备份并只读访问」，选择主盘 `LegacyLock/<密库 ID>/<代次>/vault.llvault`，或该双盘配置成功后导出的 `.llvault` 信息备份。

主盘需要信息备份和 `primary.llkey`，副盘只需 `secondary.llkey`。`.llkey` 是解锁材料，不含登录信息、备注与附件；请勿把它当作数据备份。两盘秘密必须匹配所选备份的身份和密钥代次。

成功后显示「继承人 · 只读」，可搜索、查看字段、阅读说明和保存附件。不能修改或删除资产、修改设置、更换凭据、重配双盘、删除本机密库或导出所有者备份。主进程也检查权限。

只读导入在内存中打开，不写入或覆盖本机密库，因此可以查看不同密库或历史备份。关闭、重启或锁定后需要重新选择备份和两盘，不会自动成为所有者。副盘可以提前交付；所有者日常只更新主盘，不需要拿回副盘。

拔盘会在后台检测完成后锁定，扫描有延迟。请勿把它视为瞬时硬件隔离，离开电脑应主动锁定。托盘隐藏也立即锁定。底部可临时切换中文、English、日本語，不保存设置或改变权限。

## 取得管理权限

「输入密码和密钥，接管管理权限」必须同时验证备份的密码与完整安全密钥。成功后保存为本机密库。已有不同身份或更新版本的本机密库会阻止覆盖：可使用独立系统账户导入，或先锁定、解锁本机密库，再用备份凭据合并信息。

双盘只恢复数据密钥，不包含所有者签名私钥。权限保护针对本应用和原密库签名；已读到的明文可另存，软件不能限制人的记忆、复制或截图，也不判断死亡或法律继承资格。

## 独立离线阅读器

桌面应用无法运行时，可使用 Node.js 24+ 与 `scripts/recovery-reader.cjs`、`electron/vault-core.cjs`、`electron/vault-store.cjs`，不需要第三方 npm 运行时依赖。安装目录 `resources/reader/` 包含这些文件和协议文档；macOS 对应 `Contents/Resources/reader/`。

```sh
node scripts/recovery-reader.cjs <vault.llvault> <primary.llkey> <secondary.llkey> <新的恢复输出.json>
```

阅读器验证签名并恢复全部数据，附件以 base64 保存。输出为**明文**，输出路径必须不存在，不覆盖原文件。它按两份秘密读取，不要求操作系统识别为两块 USB，用于跨系统抢救，不代表硬件防克隆。格式无到期或在线激活要求。

旧 `user-key.bin` / `heir-key.bin` 不兼容本格式。升级无法消除旧备份缺陷；请保留旧文件并参考 [开发与恢复文档](DEVELOPMENT.md)。
