# 所有者使用手册 · LVCF 3

## 创建与解锁

首次启动设置至少 12 位密码并重复确认。生成随机安全密钥，把完整 `LL3-…` 密钥保存在独立安全位置，确认备份后创建密库。重新生成钥匙会取消备份确认。密码和安全密钥不会写入 localStorage、IndexedDB 或明文设置。

默认解锁必须输入密码和安全密钥；双 USB 只能查看。所有者可在「系统设置与安全 → 本机解锁方式」选择「在本机记住安全密钥」，再次验证两项凭据后启用。以后本机锁屏及重启仍需密码，但可不再输入安全密钥。选择「改为每次输入安全密钥」可删除本机保存的密钥。锁屏页保留「改用密码和安全密钥解锁」作为备用入口。

记住的密钥使用系统安全存储加密，独立保存于本机 `local-key-v1.json`，不进入信息备份或 USB。Windows 使用 DPAPI；macOS 使用 Keychain；Linux 必须具有受支持的安全密钥存储，拒绝 basic_text/unknown 后端。此选项降低本机保护强度，尤其不能抵御同一系统账户中的恶意程序。仍需保留独立密钥备份，其他电脑导入以及导出、配置双盘、改凭据、删除密库仍需手动输入两项凭据。更换凭据或重新配置两盘会使本机记忆失效，需要重新启用。删除本机密库会一并移除本机记忆。

没有仅安全密钥、添加新凭据或双盘直接打开本机密库的入口。遗失两项凭据且没有可用的本机记忆时，已经配置的双盘仍可读取备份，但不能恢复签名管理权限。没有后台重置入口。

## 原有界面与应用设置

工作区采用「分类导航 → 信息列表 → 详细信息」三栏布局。点击中间条目即可查看右侧完整信息；列表获得焦点后可用上下方向键、Home/End 切换。搜索或切换分类会同步详情，结果为空时不保留旧详情。切换条目后密码和秘密字段重新隐藏，未填写字段不显示。列表和详情各自滚动；极窄窗口自动上下排列。

保留搜索、24 类资产、自定义字段、附件、五套背景、缩放和订阅演示。所有者点击详情右上角「编辑」后才能修改；继承会话只读查看，不显示删除按钮。单附件最多 2 MB，资产总量最多 20 MB，密库文件最多 32 MB。保存失败保留编辑窗口并显示错误，关闭窗口不能视为保存成功。

「系统设置与安全」设置 1/5/15/30/60 分钟自动锁定、继承人姓名与说明。密码和安全密钥的更换保留在顶部「密码与密钥」，设置页不再重复提供。

编辑资产时，从「添加更多 → 附上文件」选择附件。添加后才显示附件列表，可下载或移除；不再单独显示重复的上传区域。

新增资产默认展示常用类型，其余类型仍可通过分类标签或搜索找到。只有标题必填；非登录类资产可按需展开账号、密码和网址。已填写的凭证自动展开，折叠不删除内容。

「交接对象姓名」及「整体交接说明」是选填的交接记录，继承人打开备份后可查看。姓名不用于身份核验，不会通知对方，也不会授予权限。整体说明用于记录总体安排，单项资产的「这项资产如何交接」用于记录具体处理步骤。只读访问仍需要配置好的双 U 盘。

设置页选择中文、English、日本語，成功保存后下次启动继续使用。锁定或继承会话底部可临时切换语言，便于阅读；临时切换不保存设置、不改变权限。

点击关闭窗口会提示选择「锁定并隐藏到托盘」「退出应用」或「取消」。设置中的托盘选项只控制提示框默认选项，仍会询问。也可直接点击「锁定并隐藏到托盘」。托盘创建失败时保留窗口并提示；从托盘重新打开仍需解锁。常驻不等于开机自启。同一用户数据目录重复启动会恢复已有窗口。

休眠、系统锁屏、隐藏至托盘、退出和继承会话拔盘都会锁定。USB 扫描有延迟，离开电脑应主动锁定。

## 首次配置主、副 USB

1. 从「加密导入导出」进入「主盘更新与双盘解锁密钥」。插入两块不同的物理 USB，扫描并选择主盘 A、副盘 B。同盘的两个分区不合格。
2. 点击「首次配置主、副 U 盘」，重新验证密码和安全密钥。
3. 写入独立目录 `LegacyLock/<密库 ID>/<代次>/`，读回校验后才报告成功，不格式化设备。

主盘保存 `primary.llkey` 和 `vault.llvault`；副盘只保存 `secondary.llkey`。`.llkey` 是解锁秘密，不是信息数据。副盘可提前交给继承人；之后编辑数据、更换密码/安全密钥、更新主盘都不需要副盘。

前一个 LVCF 3 版本已配置的双盘仍可用，不必为了升级重配。旧版本遗留在副盘上的加密备份不会被自动删除。秘密文件可复制，物理设备检查不等于硬件防克隆。

「重新配置两盘」仅用于更换整套钥匙，需要两盘在场，生成新代次及新数据密钥。旧代次不能读取新数据，但仍可读取旧备份。失败时保留上一代本机配置；新代次残留文件不代表成功。日常更新不要使用重新配置。

## 信息备份、更新与导入

**每次编辑只保存本机，离线 USB 不会自动更新。** 编辑和设置完成后，只插入主盘、扫描选择主盘 A，再点击「更新主盘信息备份（无需副盘）」。本次会话未确认主盘版本时，应视为备份状态未知。

「验证凭据并导出信息数据」重新验证本机密码和安全密钥，导出 `.llvault`。文件包含加密的登录信息、备注、自定义字段、附件及密库设置，不包含两份 USB 秘密文件。它与 `.llkey` 解锁钥匙有明确不同用途。

所有者导入必须验证**源备份**的密码和密钥。已解锁的本机所有者会合并记录，保留本机设置、身份和 USB 配置；相同 ID 且内容一致跳过，相同 ID 内容不同作为新副本导入，不覆盖已有记录。锁定状态下完整导入仍拒绝覆盖不同身份或更新版本的本机密库。

继承者选择「双 U 盘 · 只读」，选择 `.llvault` 备份后仅在内存打开，不替换本机数据。双盘配置前导出的文件没有双盘恢复能力，需要配置成功后重新导出。

Windows、macOS、Linux 使用相同的 LVCF 3 格式。更换凭据后，重新导出并更新主盘；副盘无需更改。旧文件仍使用旧凭据，应用不能追溯更改离线副本。取消文件选择不算成功。

## 删除本机密库

设置页「删除本机密库（需两次确认）」先验证所有者密码和安全密钥，再要求输入 `DELETE`。删除本机密库、`.previous` 回退副本和本机专属临时文件，包括其中的登录信息、备注、附件与继承设置。确认在两分钟、锁定或数据更新后失效。

应用内无法撤销。外部导出文件、USB、系统快照、已下载附件不会被删除；无法保证 SSD、文件系统残留或其他副本物理不可恢复。不会把普通文件删除宣传为“彻底销毁所有副本”。

## 订阅测试与本机偏好

订阅页保留月度 ¥28、季度 ¥68、年度 ¥168 示例方案，无实际支付、扣费、自动续订或正式授权。模拟到期时主进程暂停新增、修改、删除和合并资产；所有者仍可查看、导出、管理设置、恢复试用。模拟开通不授予继承者管理权限。

主题、缩放、语言、托盘偏好、订阅演示保存在本机 `appearance-v1.json`，不随密库导出迁移。旧偏好文件自动补默认语言与托盘选项；损坏时提示并暂用默认值，不覆盖原文件、不阻止密库解锁。

复制内容在 30 秒或锁定时由主进程清除；如果剪贴板被其他内容替换则不清除。系统剪贴板历史和其他程序的副本不在此范围。

## 异常恢复

文件损坏或读取失败不会自动创建空库覆盖。请保全原文件与 `.previous`，参阅 [协议](LVCF3_PROTOCOL.md) 和 [继承人手册](HEIR_MANUAL.md)。旧 LVCF 2 等格式不能作为本次信息备份直接导入；旧迁移代码保留供维护者离线恢复，不再提供额外的应用解锁路径，见 [开发文档](DEVELOPMENT.md)。
